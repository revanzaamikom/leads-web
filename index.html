Satu kali tempel token, setelah itu aplikasi langsung kebuka terus di HP ini. Token cuma dipakai buat simpan data leads ke repo privat kamu.

  1. Buka github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories → template-chat-data
  3. Permissions → Contents → Read and write, lalu Generate
  4. Salin tokennya, tempel di atas.
